# خلوة

تطبيق محادثة فورية بسيط للجوال، بواجهات عربية (RTL)، مبني لأغراض **التجربة والاختبار** باستخدام ASP.NET Core 8 و SignalR.

> غرف خاصة بالكود أو كلمة السر — دردشة هادئة وسريعة.

---

## الفكرة

**خلوة** تتيح لك:

1. إنشاء حساب أو تسجيل الدخول  
2. إنشاء غرفة خاصة (مع كود دعوة تلقائي، وكلمة سر اختيارية)  
3. الانضمام لغرفة بالكود (+ كلمة السر إن وُجدت)  
4. الدردشة لحظياً مع مؤشر «يكتب…» وطوابع زمنية

مصمَّم للجوال أولاً، بتجربة عربية من اليمين لليسار.

---

## المزايا

| الميزة | الوصف |
|--------|--------|
| محادثة فورية | SignalR (WebSockets) |
| غرف خاصة | كود دعوة + كلمة سر اختيارية |
| مصادقة JWT | كوكيز HttpOnly |
| واجهة عربية | RTL، خطوط Cairo / IBM Plex Arabic |
| قاعدة بيانات | PostgreSQL (Neon) عبر EF Core |

---

## التقنيات

- **.NET 8** — ASP.NET Core Minimal APIs

- واجهة ثابتة في `wwwroot/index.html`

## التشغيل محلياً

### المتطلبات

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- قاعدة PostgreSQL (مثل [Neon](https://neon.tech))

### 1) استنساخ المشروع

```bash
git clone https://github.com/kalumian/websocket-demo.git
cd websocket-demo
```

### 2) إعداد اتصال قاعدة البيانات

لا تُخزَّن بيانات الاعتماد في المستودع. استخدم **User Secrets**:

```bash
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Host=...;Port=5432;Database=...;Username=...;Password=...;SSL Mode=VerifyFull;Channel Binding=Require"
```

أو عيّن متغير البيئة:

```bash
# PowerShell
$env:ConnectionStrings__DefaultConnection = "Host=...;..."
```

عند أول تشغيل تُطبَّق الـ Migrations تلقائياً وتُنشأ الجداول، مع مستخدمين وغرف تجريبية إن كانت القاعدة فارغة.

### 3) التشغيل

```bash
dotnet run
```

افتح المتصفح على العنوان الظاهر (مثلاً `http://localhost:5239`).

## حسابات تجريبية

| المستخدم | كلمة المرور |
|----------|-------------|
| أحمد | `123456` |
| سارة | `123456` |

غرف أولية (إن وُجدت بعد الـ seed):

- **عام** — بالانضمام عبر كود الدعوة  
- **تقنية** — محمية (كود + كلمة سر)

---

## كيفية الاستخدام

1. **دخول** أو **حساب جديد**  
2. **إنشاء غرفة** → يظهر كود الدعوة — شاركه بحذر  
3. **انضمام** → أدخل الكود (وكلمة السر إن طُلبت)  
4. أرسل الرسائل؛ يظهر للآخرين مؤشر الكتابة

الغرف المحفوظة تُخزَّن محلياً في المتصفح لسهولة العودة لاحقاً.

## ملاحظات للاختبار

- المشروع **تعليمي / تجريبي** وليس جاهزاً للإنتاج كما هو.  
- التخزين والجلسات تعتمد على إعداد قاعدة البيانات المحلية لديك.  
- لا ترفع كلمات السر أو Connection Strings إلى Git.  
- يُفضَّل تدوير أي بيانات اعتماد ظهرت سابقاً في المحادثات أو الـ commits القديمة.
